## 🎮 About the Game

This is a **from-scratch Unity recreation** of the iconic Hill Climb Racing mobile game. The player drives a vehicle over bumpy, physics-driven terrain, collecting **coins** and **fuel canisters** to survive as long as possible. The game features **realistic 2D vehicle physics**, **procedurally generated terrain**, a **vehicle selection system**, and **multiple collectibles** — all built with Unity's 2D physics engine and custom C# scripts.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🚗 **Multiple Vehicles** | Choose between Car and Jeep, each with different physics profiles |
| 🌄 **Procedural Terrain** | Endless, dynamically generated ground using Unity's Sprite Shape system |
| 🪙 **Coin System** | Three coin denominations (5, 25, 100) with a coin boost multiplier HUD |
| ⛽ **Fuel System** | Collect fuel canisters to keep going — run out and it's game over! |
| 🕳️ **Pothole Hazards** | Surprise pothole obstacles with animated popups and visual effects |
| 🏁 **Distance Tracking** | Real-time distance HUD with milestone celebrations |
| 💨 **Visual FX** | Rear-wheel dust trails, pedal-press animations, and parallax backgrounds |
| 🎮 **Touch + Keyboard Controls** | Gas/Brake via on-screen buttons or arrow/WASD keys |
| 🔄 **Game Over & Restart** | Smooth game-over screen with stats and instant restart |
| 🔊 **Smooth Physics** | Rigidbody interpolation for jitter-free vehicle motion |

## 🛠️ Technologies Used

- **Engine:** [Unity](https://unity.com/) (2D, Universal Render Pipeline)
- **Language:** C# (.NET)
- **Physics:** Unity 2D Rigidbody & Collider system
- **Terrain:** Unity Sprite Shape for procedural ground
- **UI:** Unity UI (TextMesh Pro, Canvas-based HUD)
- **Input:** Unity Input System + legacy `Input.GetAxisRaw`
- **Build Target:** Android (APK included)
- **Version Control:** Git + GitHub

## 🚀 Getting Started

### Prerequisites

- [Unity Hub](https://unity.com/download) installed
- **Unity Editor** version `6000.x` or compatible (check `ProjectSettings/ProjectVersion.txt`)
- Git (for cloning)

### Running in Unity Editor

```bash
# 1. Clone the repository
git clone https://github.com/Digvijayb07/CGG---Hill-Climb-Racing-.git

# 2. Open Unity Hub → click "Add" → browse to the cloned folder

# 3. Open the project in Unity Editor

# 4. In Unity, navigate to:
#    Assets → Scenes → SampleScene.unity

# 5. Press ▶ Play to start the game!
```

> **Note:** The `Library/` and `UserSettings/` folders are gitignored and will be auto-generated by Unity on first open. This is normal.

### Playing the APK (Android)

A pre-built Android APK is included in the root of the repo:

```
📦 Hill Climb.apk
```

1. Transfer `Hill Climb.apk` to your Android device
2. Enable **"Install from Unknown Sources"** in Android settings
3. Tap the APK to install and play!

## 🎯 How to Play

### Controls

| Action | Keyboard | Mobile (Touch) |
|---|---|---|
| **Accelerate** | `→` / `D` | Gas pedal button (right) |
| **Brake / Reverse** | `←` / `A` | Brake pedal button (left) |

### Objective

- 🏎️ Drive as **far as possible** without flipping or running out of fuel
- ⛽ Pick up **fuel canisters** to extend your run
- 🪙 Collect **coins** scattered across the terrain
- 🏆 Beat your **distance record**!

### Tips

- Use **small taps** on the gas pedal to maintain balance on steep hills
- **Counter-steer** mid-air to land smoothly after jumps
- Watch your **fuel gauge** — it drains constantly while driving
- Slow down over **potholes** to avoid losing control

## 🧩 Scripts Overview

| Script | Purpose |
|---|---|
| `Driver.cs` | Core vehicle physics — wheel torque, throttle smoothing, rotation control |
| `GameManager.cs` | Singleton manager — game over flow, time scale, restart logic |
| `EnvironmentGenerator.cs` | Procedural terrain & obstacle generation |
| `FuelManager.cs` | Fuel consumption and game-over trigger on empty tank |
| `ScoreManager.cs` | Tracks and persists the player's score |
| `CollectibleSpawn.cs` | Spawns coins and fuel canisters along the terrain |
| `Collectible.cs` | Base collectible pickup logic |
| `CoinBoost.cs` | Coin multiplier boost mechanic |
| `CoinBoostHUD.cs` | Animated HUD for coin boost display |
| `EndlessDistanceHUD.cs` | Real-time distance tracker UI |
| `CGGDistanceMilestoneHUD.cs` | Milestone celebration overlays (e.g., every 500m) |
| `CGGParallaxBackground.cs` | Multi-layer scrolling parallax background |
| `PotholeHazard.cs` | Pothole obstacle logic and damage |
| `PotholeVisual.cs` | Animated pothole visual effects |
| `PotholePopupUI.cs` | Popup UI when a pothole is hit |
| `VehicleSelector.cs` | Pre-game vehicle selection system |
| `GameOverUI.cs` | Game-over overlay with stats display |
| `GameOverStatsUI.cs` | Distance and coin stats on game-over screen |
| `RearWheelDustFX.cs` | Dust particle trail on rear wheel |
| `PedalPressFX.cs` | Visual feedback on pedal press |
| `SubtleGameplayFX.cs` | Ambient gameplay polish effects |
| `BlockEnd.cs` | Marks the end boundary of a terrain block |
| `CollectFuel.cs` | Trigger handler for fuel canister pickup |
| `DriverDeadHead.cs` | Physics ragdoll for driver's head on crash |
